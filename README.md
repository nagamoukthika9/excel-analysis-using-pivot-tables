# Excel PivotTable Basics

## Project Overview
This project focuses on analyzing Superstore sales data using Microsoft Excel PivotTables. The main objective is to create quick summaries and understand sales performance across different categories, regions, and months.

## Dataset
- Dataset: Sample Superstore Sales
- Total Records: 9,994
- Tool Used: Microsoft Excel

## Tasks Performed
1. Imported and organized the raw sales dataset.
2. Created a PivotTable-style summary for sales by category.
3. Created a summary for sales by region.
4. Analyzed monthly sales trends.
5. Calculated total sales, profit, quantity, and order counts.
6. Created charts to visualize the results.

## Key Insights
- Total Sales: $2,297,200.86
- Total Profit: $286,397.02
- Total Orders: 5,009
- Technology generated the highest sales among the three categories.
- The West region recorded the highest sales.

## Deliverables
- Raw Data
- Sales by Category
- Sales by Region
- Monthly Sales Analysis
- Short Insights
- Charts and Visualizations
